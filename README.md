# 🛡️ Insurance Agent Samurai

Insurance Agent Samurai is a full-stack web application designed to help insurance agents manage customers, insurance policies, and premium calculations through a simple web portal.

## 🌐 Live Application

**Frontend / Live Website:**  
https://insurance-agent-samurai.onrender.com

**Backend API:**  
https://insurance-agent-samurai-api.onrender.com

## 🚀 Features

- Agent registration
- Agent login and authentication
- Agent dashboard
- Customer management
- Add customers
- Search customers by name
- Delete customers
- Insurance policy management
- Search policies by name and type
- Active policy listing
- Premium calculator
- PostgreSQL database
- REST APIs
- Responsive web interface

## 🛠️ Technologies Used
